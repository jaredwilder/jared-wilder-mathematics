# Jared Wilder - mathematics

Author: **Jared Wilder**. Every public mathematics repository, by subject, one line each from the repository's own README.

**97 public repositories.** The full record is larger: a further 8 private research repositories and 15 sealed research vaults (machine-found theorems kernel-checked in Lean, the Erdős #552 term a(39)=46, the complete Erdős Lean record) are available on request.

Repositories cited by others are marked **cited**. Older repository names still work (GitHub redirects them).
